# Visão do Produto

## Vision Statement

Criar um ambiente de prática que permita a pessoas em início de carreira experimentar **como é trabalhar como Engenheiro de Dados**, resolvendo demandas contextualizadas em uma empresa fictícia, utilizando ferramentas e práticas próximas das encontradas no mercado.

## Por que o projeto existe

O aprendizado tradicional costuma responder:

> "Como usar SQL, Python ou Airflow?"

Este projeto pretende responder:

> "Eu conheço SQL, Python ou Airflow. Como uso isso para resolver uma demanda real de Engenharia de Dados?"

O foco, portanto, é reduzir a distância entre **estudo** e **experiência prática**.

## Proposta de valor

O simulador deve oferecer:

- contexto de negócio;
- ambiente técnico reproduzível;
- problemas progressivos;
- liberdade para investigação;
- múltiplas soluções possíveis quando aplicável;
- critérios objetivos de aceite;
- validação automatizada;
- práticas reais de desenvolvimento e entrega.

## Posicionamento

O projeto **não é um curso**.

Não deverá explicar detalhadamente como aprender cada tecnologia. O participante poderá utilizar documentação, cursos, vídeos, LLMs e outras fontes externas para adquirir o conhecimento necessário.

O simulador fornece o **problema e o ambiente onde esse conhecimento será colocado à prova**.

## Metáfora do produto

A experiência pode ser entendida como um:

**Estágio simulado de Engenharia de Dados.**

O participante entra em uma empresa fictícia, conhece seus sistemas e dados, recebe demandas e evolui conforme entrega soluções cada vez mais complexas.

## Critério de sucesso da visão

O produto terá atingido sua visão quando um participante puder dizer:

> "Eu não apenas estudei essas tecnologias; eu já as utilizei para resolver problemas semelhantes aos encontrados no trabalho de Engenharia de Dados."
