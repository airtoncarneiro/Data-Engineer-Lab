# Tasks concluídas

Este diretório preserva especificações de tasks que já foram implementadas e validadas.

Uma task deve ser movida de `../active/` para cá somente quando:

- o escopo solicitado estiver concluído;
- critérios de aceite aplicáveis estiverem satisfeitos;
- testes, lint, tipagem e demais validações relevantes tiverem sido executados quando disponíveis;
- documentação impactada estiver consistente;
- a alteração tiver sido publicada conforme o workflow da tarefa.

O arquivo da task deve permanecer como registro do contrato executado. Não o transforme em changelog; histórico de implementação pertence ao Git e à documentação técnica apropriada.
